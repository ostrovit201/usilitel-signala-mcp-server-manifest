# MCP-сервер каталога «Усилитель сигнала»

**https://mcp.usilitel-signala.ru/mcp**

Это официальный MCP-сервер интернет-магазина [«Усилитель сигнала»](https://usilitel-signala.ru). Подключите его своему ИИ-помощнику, чтобы поручить ему подбор оборудования для усиления сотовой связи и мобильного интернета — репитеров, готовых комплектов, антенн, бустеров, кабеля и 4G-роутеров — по актуальным ценам, наличию и характеристикам. Актуальный список тулов и инструкции для начала работы — на странице MCP-сервера.

## Быстрый старт

Добавьте своему ИИ-помощнику:

```
Подключись к MCP-серверу «Усилитель сигнала» по ссылке https://mcp.usilitel-signala.ru/mcp.
Если нет возможности осуществлять сетевые вызовы, объясни, как подключить MCP-сервер в интерфейсе.
Для теста подбери готовый комплект усиления сотовой связи и интернета для дачи 150 м² в Подмосковье:
оператор МТС, только в наличии, до 25 000 ₽. Покажи 3 варианта с ценой, частотами, площадью,
ссылкой на страницу и паспортом в PDF.
```

Подключение: транспорт **Streamable HTTP**, адрес `https://mcp.usilitel-signala.ru/mcp`, авторизация не нужна.

- **Claude**: Настройки → Коннекторы → «Добавить свой коннектор».
- **Claude Code**: `claude mcp add --transport http usilitel-signala https://mcp.usilitel-signala.ru/mcp`
- **MCP Inspector**: `npx @modelcontextprotocol/inspector` → Streamable HTTP → адрес сервера.

## Данные

Каталог (больше 1000 моделей VEGATEL, ДалСВЯЗЬ, Baltic Signal, KROKS), цены, наличие, характеристики, PDF-паспорта, тексты разделов и услуг, статьи блога. Сервер сверяется с сайтом usilitel-signala.ru каждые 5 минут: новые товары, цены, характеристики и статьи появляются автоматически. Сервер только читает публичные данные сайта: корзины, авторизации и персональных данных нет.

## Релизы

### 1.0. Публичный MCP-сервер
**Октябрь 2026** — первая версия, 13 тулов:
- `usilitel_products_search` — поиск по каталогу: слова, раздел, бренд, частота, оператор, объект, цена, наличие, сортировка
- `usilitel_product_details` — полная карточка: характеристики, комплектация, фото, PDF-документы
- `usilitel_products_compare` — сравнение 2–5 моделей
- `usilitel_equipment_pick` — подбор под объект, площадь, операторов или частоты из замера, бюджет
- `usilitel_catalog_sections` — разделы, подборки, бренды, услуги
- `usilitel_page_text` — тексты разделов, подборок и услуг с вопросами-ответами
- `usilitel_articles`, `usilitel_article` — статьи блога
- `usilitel_content_search` — поиск по статьям и текстам сайта
- `usilitel_catalog_changes` — журнал изменений: новые и снятые товары, цены, наличие, новые статьи
- `usilitel_catalog_status` — свежесть данных
- `usilitel_contacts` — контакты и условия магазина
- `usilitel_refresh` — принудительная сверка с сайтом
